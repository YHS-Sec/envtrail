What this report includes

EnvTrail compares selected environment metadata. It never embeds a complete snapshot or reads environment-variable values into this report.

Included when available

  • Runtime and package-manager versions
  • Operating system and CPU architecture
  • Declared project tool requirements
  • Environment-variable names and presence
  • Lockfile comparison results

Excluded

  • Environment-variable values
  • Absolute project and home paths
  • Source code and file contents
  • Remote scripts, fonts, and tracking

Review names and metadata before sharing: project requirements and environment-variable names can still reveal context about your project. This report is a diagnostic aid, not a guarantee of identical application behavior.
