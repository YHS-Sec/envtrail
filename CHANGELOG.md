# Changelog

Notable user-facing changes are recorded here. The project uses semantic versions; snapshot schema versions are tracked separately.

## 0.1.0 — 2026-10-25

Initial release.

- Capture a local Node.js project environment in a versioned JSON snapshot.
- Compare a baseline with another snapshot or the current environment.
- Inspect project requirement mismatches, version differences, and environment variable presence.
- Export comparison results as terminal output, JSON, or a standalone HTML report.
- Choose whether error or warning findings cause a failing exit status.
- Keep variable values, usernames, hostnames, and absolute project paths out of snapshots.
- Include a synthetic demo, automated checks, and open-source contribution policies.
